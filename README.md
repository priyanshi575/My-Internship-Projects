**My Internship Projects**

This repository contains two beginner-level Python projects developed as part of my learning and internship preparation.

Project1 : Customer Service Chatbot

A rule-based customer service chatbot developed using Python and Flask. It provides automated responses to common customer queries related to order status, delivery, refunds, returns, payments and cancellations.

Technologies Used: Python, Flask, HTML, CSS, JavaScript.

Key Features:

- Interactive chatbot interface.
- Automated responses to customer queries.
- Quick question suggestions.
- Simple and user-friendly design.

**Project 2: Movie Recommendation System**

A content-based movie recommendation system developed using Python. It recommends similar movies based on their genres using Cosine Similarity.

Technologies Used: Python, Pandas, Scikit-learn.

Key Features:

- Movie dataset created using Pandas.
- Movie genre analysis using CountVectorizer.
- Cosine Similarity to identify similar movies.
- Recommends five movies based on user input.

Learning Outcomes

Through these projects, I gained practical experience in Python programming, data handling, basic machine learning concepts and web development using Flask.
